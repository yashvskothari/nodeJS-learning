Designing a REST API - To store Json data , 

routes - 
GET /users- reder an HTML doc
GET /api/users- List all users in json format

GET /api/users/1 - Get the user with ID = 1
GET /api/users/2- Get the user with ID = 2

these 1, 2,3,4,... are dynamic path parameters - a ":" colon is used before it 
GET /api/user/:id


POST /api/users - Create new user

Patch /api/user/1 - Edit the user with ID 1

DELETE /api/user/1 - Delete the user with ID 1

(get the demo data from mockaroo.com)

app.get("/api/users/:id", (req, res) => {
  // first we need to get the id
  const id = Number(req.params.id);
  // req.params.id is a string , so we need to first convert it into number
  // finding the appropriate user whose id matches with the requested id
  const user = users.find((user) => user.id === id);
  return res.json(user);
});
