# Node.js Learning Repository

A structured repository containing my journey of learning and exploring **Node.js**, from the fundamentals to building backend applications and understanding the Node.js ecosystem.

## About

This repository serves as my personal learning space for Node.js.

It contains concepts, examples, experiments, practice programs, and small projects that I build while learning. Each folder represents a different concept or stage of my learning.

The goal is not just to learn the syntax, but to understand how Node.js works internally and how it is used to build real-world backend applications.

## How to Run

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the required folder:

```bash
cd nodejs/<folder-name>
```

Install dependencies if the folder contains a `package.json`:

```bash
npm install
```

Run the application using the script defined in that folder's `package.json`.

For example:

```bash
npm start
```

or

```bash
npm run dev
```
